# אמא במשרד – Pastry Box Platform

פלטפורמה להזמנת מגשי מאפים: אתר תפריט ללקוחות ולוח ניהול הזמנות למנהל.

## איך הלקוח מזמין (אחרי שהאתר באוויר)

1. נכנסים לכתובת האתר (למשל `https://your-app.up.railway.app`).
2. בוחרים גודל מגש: 35 / 50 / 70 יח'.
3. לוחצים "להזמנה" וממלאים: כמות קופסאות, שם, טלפון, אימייל (אופציונלי), כתובת למשלוח, תאריך משלוח (לפחות 3 ימים מראש).
4. לוחצים "שליחת הזמנה" – ההזמנה נשמרת. התשלום (bit) מתבצע מחוץ לאתר – לפי מה שתגדירו ללקוח.

## איך אתם (המנהל) משתמשים

1. נכנסים ל־**/manager** (למשל `https://your-app.up.railway.app/manager`) ומזינים סיסמה.
2. רואים את כל ההזמנות (פעילות + היסטוריה), מסננים לפי סטטוס/מוצר/תאריך, מייצאים לאקסל.
3. מעדכנים סטטוס: חדש → אושר → נמסר, ומעלים קבצים (חשבונית, צילום bit) לכל הזמנה.
4. סיסמת מנהל: מוגדרת ב־**משתנה סביבה** `MANAGER_PASSWORD` (לא בקוד – לא עולה ל-Git). מקומית: קובץ `.env` עם `MANAGER_PASSWORD=הסיסמה`. באינטרנט: הגדרת המשתנה בשרת. ראה [USER_MANUAL.md](./USER_MANUAL.md).

## העלאה לאינטרנט (איך הלקוחות יגיעו ויוכלו להזמין)

האפליקציה שומרת הזמנות וקבצים על הדיסק של השרת. כדי שהכל יעבוד ויישמר:

- **הדרך הקלה:** פריסה ב־**Railway** – חיבור ריפו מ־GitHub, הוספת Volume לאחסון `data/`, וקבלת קישור. פרטים מלאים ב־**[DEPLOYMENT.md](./DEPLOYMENT.md)**.
- **אפשרויות נוספות:** Render (עם דיסק מתמשך), או שרת משלכם (VPS) עם Node ו־PM2 – הכל מפורט ב־DEPLOYMENT.md.

אחרי הפריסה – שיתוף הקישור ללקוחות (להזמנות) והקישור ל־/manager (לכם).

## מה כולל

- **אתר ללקוח** (`/`): תפריט עם 3 גדלי מגש (35, 50, 70 יח') במחיר 8 ₪ ליחידה. לחיצה על "להזמנה" מובילה לטופס הזמנה.
- **צ'ק-אאוט** (`/checkout?box=35|50|70`): טופס פרטים, כתובת, תאריך משלוח (לפחות 3 ימים מראש). ההזמנה נשמרת ומופיעה במנהל.
- **אתר מנהל** (`/manager`): רשימת כל ההזמנות, עדכון סטטוס (חדש → אושר → נמסר), רענון אוטומטי כל 15 שניות.

## העלאת הפרויקט ל-GitHub (צעד אחר צעד)

1. **התקן Git** במחשב (אם עדיין אין): [https://git-scm.com/downloads](https://git-scm.com/downloads) – התקן והפעל מחדש את הטרמינל.

2. **צור חשבון GitHub** (אם אין): [https://github.com](https://github.com) → Sign up.

3. **צור ריפו חדש ב-GitHub:**
   - GitHub → **New repository** (או הכפתור הירוק "+" → New repository).
   - **Repository name:** למשל `pastry-box-platform`.
   - **Public** → Create repository.
   - אל תסמן "Add a README" או ".gitignore" – הפרויקט כבר כולל אותם.

4. **במחשב – בתיקיית הפרויקט** (פתח טרמינל בתיקייה שבה נמצא `package.json`):

   ```bash
   git init
   git add .
   git status
   ```
   (`git status` יראה את הקבצים שיועלו. תיקיות `node_modules`, `.next` ו־`data` לא ייכללו כי הן ב־`.gitignore` – וזה בסדר.)

   ```bash
   git commit -m "Initial commit - pastry box platform"
   ```

5. **חבר את הפרויקט לריפו ב-GitHub** (החלף `YOUR_USERNAME` ו־`pastry-box-platform` בשם המשתמש והריפו שיצרת):

   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/pastry-box-platform.git
   git branch -M main
   git push -u origin main
   ```

6. **אם GitHub מבקש התחברות:**  
   - בדפדפן ייפתח חלון להתחברות, או שיבקשו **Personal Access Token**.  
   - ליצירת Token: GitHub → Settings → Developer settings → Personal access tokens → Generate new token.  
   - סמן `repo`, צור, והדבק את ה-Token במקום הסיסמה כשמבקשים.

אחרי ה־`git push` הפרויקט יופיע ב-GitHub. תיקיית **data/** (הזמנות וקבצים שהועלו) **לא** תועלה – היא ב־`.gitignore`. אם תרצה לגבות גם אותה, תצטרך להעלות אותה בנפרד (למשל קובץ ZIP פרטי) או להסיר את `data` מ־`.gitignore` (פחות מומלץ אם יש שם מידע רגיש).

## העברת הפרויקט למחשב אחר

**אפשרות 1 – Git (מומלץ)**  
1. במחשב הנוכחי: אם עדיין לא יצרת ריפו, `git init` ואז דחיפה ל־GitHub/GitLab.  
2. במחשב החדש: `git clone <כתובת-הריפו>`, אחר כך `cd pastry-box-platform` ו־`npm install`.  
3. אם רוצים להעביר גם **הזמנות וקבצים**: העתק את תיקיית `data/` (כולל `orders.json` ו־`uploads/`) מהמחשב הישן לתוך הפרויקט במחשב החדש. (תיקיית `data` לא נשמרת ב־Git.)

**אפשרות 2 – העתקה ידנית**  
1. צור קובץ ZIP של כל תיקיית הפרויקט **בלי** `node_modules` ו־`.next` (אין צורך להעביר אותם).  
2. אם רוצים לשמור הזמנות – כלול בתוך ה־ZIP את תיקיית `data/`.  
3. במחשב החדש: חלץ את ה־ZIP, פתח טרמינל בתיקייה והרץ `npm install`.  
4. להרצה: `npm run dev` או `npm run build` ואז `npm start`.

## התקנה והרצה

1. **התקן Node.js** (גרסה 18 או חדשה) מ־[https://nodejs.org](https://nodejs.org).
2. **(אופציונלי – סיסמת מנהל)** כדי להגדיר סיסמה ל־/manager: העתק את `.env.example` ל־`.env` והגדר `MANAGER_PASSWORD=הסיסמה_שלך`. הקובץ `.env` לא עולה ל-Git. אם לא מגדירים – בהרצה מקומית (development) ברירת המחדל היא `admin1996`.
3. פתח טרמינל בתיקיית הפרויקט והרץ:

```bash
cd pastry-box-platform
npm install
npm run dev
```

3. בדפדפן: **http://localhost:3000** – תפריט ללקוחות, **http://localhost:3000/manager** – לוח מנהל.
